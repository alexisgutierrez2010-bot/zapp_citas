0. INTRODUCCIÓN
----------------------------------------

**Objetivo del Documento:**
Este documento sirve como la referencia técnica central para el ecosistema de aplicaciones "ZApp Citas". Su objetivo es proporcionar una visión clara y detallada de la arquitectura del software, la estructura de la base de datos, la funcionalidad de cada componente y las interacciones entre ellos.

**Resumen General:**
El sistema ZApp Citas está compuesto por tres aplicaciones principales que trabajan de forma coordinada:

1.  **Panel de Administración (zapp_citas):** Es el núcleo del sistema, desarrollado en PHP tradicional. Permite la gestión completa de negocios, usuarios, clientes, servicios, citas y configuraciones globales.
2.  **SPA del Propietario (spa_owner):** Una Single-Page Application (HTML + JavaScript) diseñada para que los dueños de negocios gestionen su agenda, clientes y servicios de forma rápida y moderna.
3.  **SPA del Cliente (spa_cliente):** Una Single-Page Application (HTML + JavaScript) que permite a los clientes finales registrarse, ver su historial y gestionar su perfil.

**Estructura de Llamados:**
El sistema utiliza una arquitectura mixta:
- El Panel de Administración sigue un modelo de carga de páginas PHP tradicional (ej. `clientes_lista.php` -> `clientes_editar.php`).
- Las SPAs (`spa_owner.html` y `spa_cliente.html`) son interfaces estáticas que consumen datos de un conjunto de scripts PHP que actúan como una API RESTful (ej. `api_owner_horario_disponible.php`).

1. LISTADO DE PROGRAMAS Y FUNCIONALIDAD
----------------------------------------

A continuación se detalla cada programa y su propósito dentro del sistema.

**A. Archivos Centrales y de Configuración:**
--------------------------------------------
* `config.php`: Define las credenciales de conexión a la base de datos y las constantes de configuración de SMTP.
* `audit_log.php`: Contiene la función `registrar_auditoria()` para registrar eventos clave en la tabla `j101_auditoria`.
* `index.php`: Portal de bienvenida principal. Muestra accesos a las tres aplicaciones y utiliza el `footer.php` centralizado.
* `footer.php`: Pie de página universal para toda la aplicación (panel de admin y SPAs). Incluye el script de Bootstrap y un reloj en tiempo real.
* `navbar.php`: Barra de navegación superior, exclusiva para el panel de administración.
* `get_image.php`: Script seguro para servir la imagen de fondo de un negocio desde la base de datos.

**B. Autenticación y Sesión:**
-----------------------------
* `auth_check.php`: **Guardián de sesión** para el panel de administración. Inicia la sesión (`session_start()`), verifica si el usuario está autenticado y controla el tiempo de inactividad. Se incluye en todas las páginas protegidas.
* `api_owner_session_check.php`: Guardián de seguridad para la API de la SPA del Propietario.
* `api_cliente_session_check.php`: Guardián de seguridad para la API de la SPA del Cliente.
* `sesion_iniciar.php`: Muestra el formulario de login para el panel de administración. Utiliza el `footer.php` centralizado.
* `procesar_login.php`: Valida las credenciales del panel de administración y crea la sesión.
* `logout.php`: Cierra la sesión del panel de administración.
* `olvide_clave.php` / `procesar_olvide_clave.php`: Gestionan la recuperación de contraseñas.

**C. Panel de Administración (zapp_citas):**
---------------------------------------------

  **C.1. Gestión de Negocios:**
  * `negocios_configuracion.php`: Formulario principal para ver y editar todos los detalles de un negocio (datos, horarios, período de prueba).
  * `negocios_actualizar.php`: Procesa y guarda los cambios del formulario de configuración del negocio.
  * `crear_negocio.php`: Formulario para crear un nuevo negocio y su usuario propietario asociado.
  * `negocios_crear.php`: Procesa y guarda el nuevo negocio y su usuario.
  * `negocios_eliminar.php`: Realiza el borrado lógico de un negocio.

  **C.2. Gestión de Usuarios:**
  * `usuarios_lista.php`: Muestra la lista de todos los usuarios y el formulario para crear uno nuevo.
  * `usuarios_crear.php`: Procesa la creación de un nuevo usuario.
  * `usuarios_editar.php`: Formulario para editar los datos de un usuario existente.
  * `usuarios_actualizar.php`: Procesa y guarda los cambios de un usuario.
  * `usuarios_eliminar.php`: Elimina un usuario de la base de datos.
  * `perfil_ver.php` / `perfil_actualizar.php`: Permiten al usuario actual cambiar su propia contraseña.

  **C.3. Gestión de Clientes:**
  * `clientes_lista.php`: Muestra la lista de clientes y el formulario para crear uno nuevo.
  * `clientes_crear.php`: Procesa la creación de un nuevo cliente.
  * `clientes_editar.php`: Formulario para editar los datos de un cliente.
  * `clientes_actualizar.php`: Procesa y guarda los cambios de un cliente.
  * `clientes_eliminar.php`: Realiza el borrado lógico de un cliente (lo marca como inactivo).

  **C.4. Gestión de Servicios:**
  * `servicios_lista.php`: Muestra la lista de servicios y el formulario para crear uno nuevo.
  * `servicios_crear.php`: Procesa la creación de un nuevo servicio.
  * `servicios_editar.php`: Formulario para editar un servicio.
  * `servicios_actualizar.php`: Procesa y guarda los cambios de un servicio.
  * `servicios_eliminar.php`: Realiza el borrado lógico de un servicio.

  **C.5. Gestión de Categorías:**
  * `categorias_lista.php`: Muestra la lista de categorías y un enlace para crear una nueva.
  * `categoria_crear.php`: Formulario para crear una nueva categoría.
  * `categorias_procesar_crear.php`: Procesa la creación de la categoría.
  * `categoria_editar.php`: Formulario para editar una categoría.
  * `categoria_actualizar.php`: Procesa y guarda los cambios de una categoría.
  * `categoria_eliminar.php`: Elimina una categoría de la base de datos.

  **C.6. Gestión de Citas:**
  * `citas_lista.php`: Muestra la lista de citas del día y el formulario para agendar (Servicio o Reunión).
  * `citas_crear.php`: Procesa la creación de una nueva cita y sus invitados si aplica.
  * `citas_editar.php`: Formulario para editar una cita y gestionar sus invitados.
  * `citas_actualizar.php`: Procesa y guarda los cambios de una cita y sus invitados.
  * `citas_eliminar.php`: Elimina una cita de la base de datos.
  * `citas_actualizar_estado.php`: Cambia el estado de una cita (Completada, Cancelada, etc.).
  * `citas_confirmar_envio.php`: Página intermedia para confirmar el envío de notificaciones por correo.
  * `enviar_email.php`: Script central que construye y envía los correos de notificación (para citas y reuniones).
  * `calendario_ver.php`: Muestra una vista de calendario de todas las citas.

  **C.7. Gestión de Documentos:**
  * `seleccionar_resumen.php`: Muestra la lista de documentos, permite ver, editar, enviar y subir nuevos.
  * `documento_editar.php`: Muestra un editor de texto enriquecido para modificar archivos .txt.
  * `documento_subir.php`: Procesa la subida de archivos .txt y .pdf.
  * `documento_enviar_pdf.php`: Formulario para especificar el destinatario al enviar un PDF.
  * `enviar_resumen.php`: Script que envía por correo el contenido de un .txt o un .pdf como adjunto.

  **C.8. Localizaciones:**
  * `paises_lista.php`: Gestiona la lista de países.
  * `paises_crear.php`, `paises_editar.php`, `paises_actualizar.php`, `paises_eliminar.php`: CRUD para países.
  * `estados_lista.php`: Gestiona la lista de estados de un país específico.
  * `estados_crear.php`, `estados_editar.php`, `estados_actualizar.php`, `estados_eliminar.php`: CRUD para estados.

**D. API para SPA del Propietario (spa_owner):**
------------------------------------------------
* `api_owner_login.php`: Valida las credenciales del propietario y crea su sesión.
* `api_owner_logout.php`: Cierra la sesión del propietario.
* `api_owner_horario_disponible.php`: Devuelve los slots de tiempo y las citas de un día específico.
* `api_owner_cita_detalle.php`: Devuelve los detalles completos de una cita, incluyendo invitados.
* `api_owner_cita_crear.php`: Permite al propietario crear una nueva cita (Servicio o Reunión).
* `api_owner_clientes.php`: Devuelve la lista de clientes activos del negocio.
* `api_owner_servicios.php`: Devuelve la lista de servicios activos del negocio.
* `api_owner_negocio_detalle.php`: Devuelve los detalles de configuración del negocio.
* `api_owner_negocio_actualizar.php`: Actualiza la configuración del negocio.
* `api_owner_perfil_detalle.php`: Devuelve los datos del perfil del propietario.

**E. API para SPA del Cliente (spa_cliente):**
-----------------------------------------------
* `api_cliente_login.php`: Valida el número de celular del cliente y crea su sesión.
* `api_cliente_logout.php`: Cierra la sesión del cliente.
* `api_cliente_registro.php`: Registra un nuevo cliente en la base de datos.
* `api_cliente_perfil.php`: Obtiene y actualiza los datos del perfil del cliente.

* `api_cliente_historial.php`: Devuelve el historial completo de citas del cliente.
* `api_negocios_publicos.php`: Devuelve la lista de negocios activos, agrupados por categoría.

* `api_paises.php` / `api_estados.php`: Devuelven las listas de localizaciones para los formularios.


**F. Arquitectura de Sesión:**
-----------------------------
El sistema maneja dos patrones de sesión distintos:

1.  **Panel de Administración (PHP Tradicional):**
    - El script guardián `auth_check.php` es el **responsable de iniciar la sesión** con `session_start()`.
    - Las páginas que lo incluyen (ej. `dashboard.php`, `clientes_lista.php`) **NO deben** llamar a `session_start()` por su cuenta.

2.  **APIs para SPAs (JavaScript):**
    - Cada script de API (ej. `api_owner_horario_disponible.php`) es **responsable de iniciar su propia sesión** con `session_start()` al principio de todo.
    - Después, incluyen a su respectivo guardián (ej. `api_owner_session_check.php`), cuya única función es **verificar** la sesión ya iniciada, pero **NO iniciarla**.

Esta separación es crucial para evitar conflictos de "sesión ya iniciada" y asegurar el correcto funcionamiento de ambos sistemas.

3. PROGRAMAS DE USO COMÚN
----------------------------------------

* `auth_check.php`: Es el archivo más crítico para la seguridad del panel de administración.
* `config.php`: Esencial para la conexión a la base de datos en todos los scripts.
* `citas_lista.php`: Es el centro de operaciones para la gestión diaria de citas.
* `negocios_configuracion.php`: Es la página principal para la configuración de un negocio.
* `api_owner_horario_disponible.php`: Es la API más importante para la SPA del propietario, ya que construye el cronograma visual.
