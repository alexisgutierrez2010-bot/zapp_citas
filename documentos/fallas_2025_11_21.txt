Fecha de Creación: 21 de Noviembre de 2025

Este documento registra las fallas críticas y persistentes encontradas durante el desarrollo, con el objetivo de centralizar su análisis y solución.

1. FALLA CRÍTICA: "Unexpected end of JSON input"
----------------------------------------

* **Síntoma:** Al navegar a ciertas secciones de las aplicaciones SPA (principalmente "Mi Negocio" y "Agenda Semanal" en `spa_owner`), la aplicación falla y la consola del navegador muestra el error "SyntaxError: Unexpected end of JSON input" o "Unexpected token '<'".

* **Análisis Preliminar:**
  - Este error ocurre cuando el código JavaScript espera recibir una respuesta en formato JSON desde una API, pero en su lugar recibe una respuesta vacía o una página de error HTML.
  - Se ha identificado que esto sucede cuando el script PHP de la API encuentra un error fatal antes de poder generar una respuesta JSON válida.

* **Causas Raíz Identificadas (Hipótesis):**
  1.  **Error de Secuencia en la API:** El `header('Content-Type: application/json');` se ejecuta antes de que el script de validación de sesión (`api_owner_session_check.php`) se complete. Si la sesión expira, el script de sesión intenta enviar su propio error JSON, pero choca con la cabecera ya establecida, resultando en una respuesta vacía.
  2.  **Falta de Robustez en la Conexión a BD:** Los scripts de la API no verifican si la conexión a la base de datos (`$conn`) fue exitosa antes de intentar usarla. Un fallo en la conexión a la BD provoca un error fatal en PHP.
  3.  **Inclusión Incorrecta de Archivos:** Un `require_once` con una ruta incorrecta puede causar un error fatal que interrumpe la ejecución del script.

* **Plan de Acción:**
  - [X] Estandarizar el encabezado de todos los scripts de API para que sigan el orden correcto: 1) `require_once 'api_..._session_check.php';`, 2) `header('Content-Type: application/json');`, 3) `require_once 'config.php';`. (Realizado en `api_owner_negocio_detalle.php` y `api_owner_agenda_semanal.php`).
  - [X] Añadir un bloque de verificación de conexión a la BD en todos los scripts de API inmediatamente después de incluir `config.php`. (Realizado en `api_owner_negocio_detalle.php` y `api_owner_agenda_semanal.php`).

2. FALLA DE RENDERIZADO: Menú no aparece en `spa_owner`
----------------------------------------

* **Síntoma:** Después de iniciar sesión en el Portal del Propietario, el menú de navegación principal no se muestra.

* **Análisis Preliminar:** La función `updateNavbar()` que dibuja el menú no se está llamando en el momento adecuado o está en conflicto con el renderizado de la vista principal.

* **Plan de Acción:**
  - [X] Ajustar el flujo de ejecución en `handleLogin` para asegurar que `updateNavbar()` se llame antes de `renderCitasView()`.
